同一 lock 可同时需要交易级签名和多个 OTX 签名（base + 每个包含其输入的 append 段），每个都必须通过。没有任何 cobuild witness 时不产生交易级要求 → 40。mask 的具体含义（哪些字段参与签名）见设计文档 docs/superpowers/specs/2026-06-22-otx-mask-default-value-signing-design.md，本页只列代码中的长度规则。One lock may need a tx-level signature and several OTX signatures at once (base + every append segment containing its inputs); each must pass. With no cobuild witness at all there is no tx-level requirement → 40. What the masks select for signing is described in docs/superpowers/specs/2026-06-22-otx-mask-default-value-signing-design.md; this page lists only the length rules in the code.
