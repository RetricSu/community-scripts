没有销毁池的路径：state type 要求同 type 输出恰好为 [0]，池一旦创建只能继续更新。全交易只允许一个 state 输出（同 code_hash），所以多个池不能在同一交易中更新。There is no pool-destruction path: the state type requires same-type outputs to be exactly [0], so a pool can only be updated after creation.
