A截止前：合并（输入 since = 0）Before deadline: merge (input since = 0)

Inputs 输入Inputs
≥2 个 pledge≥2 pledgesCell{ lock: { codeHash: PLEDGE_LOCK, args: campaign_hash 32B ‖ deadline 8B ‖ backer_lock_hash 32B }, type: T, data[64..72] = aᵢ }, since = 0
Outputs 输出Outputs
唯一合并 cellsingle merged cellCell{ lock: 同一 lock, capacity = Σ输入, type: T, data[64..72] = Σaᵢ }Cell{ lock: same lock, capacity = Σinputs, type: T, data[64..72] = Σaᵢ }
lock args 字节布局（72B）lock args byte layout (72B)
campaign_type_script_hash32B
deadline_block8B
backer_lock_hash32B
  • campaign_type_script_hash32B所属 campaign 的 type script hash；截止后结算时在 cell_deps 中按它查找 campaign cell（合并不检查）type script hash of the campaign; on settlement it is looked up in cell_deps (not checked on merge)
  • deadline_block8B截止区块 u64 LE；截止后结算时 since 须 ≥ 它（合并不检查）deadline block u64 LE; on settlement since must be ≥ it (not checked on merge)13
  • backer_lock_hash32B认捐人 lock hash；截止后退款或找零的去向（合并不检查）backer lock hash; refund / overhead destination on settlement (not checked on merge)32

限制Constraints

  • args≥ 72 字节≥ 72 bytes10
  • inputsgroup 输入 ≥ 2（否则为 40）≥ 2 group inputs (otherwise 40)40
  • outputs恰好 1 个同 lock 输出（0 个 → 41，多个 → 42）exactly one output with the same lock (none → 41, several → 42)41 / 42
  • capacity输出 capacity = Σ输入 capacity（合并不扣手续费）output capacity = Σ input capacity (no fee taken)43
  • type所有输入与输出 type 相同且非空all inputs and the output share one non-empty type45
  • data输入、输出 data ≥ 72 字节且 amount 之和相等（输入 data 过短也报 46）input/output data ≥ 72 bytes and amounts sum equal (a short input also gives 46)46
  • u64累加溢出（capacity 或 amount）addition overflows (capacity or amount)33
  • lock hash同组输入 lock hash 不一致group inputs with differing lock hash防御性检查：Source::GroupInput 下实际不可达defensive check: unreachable in practice under Source::GroupInput44
  • load读取输入 / 输出 capacity、lock hash、type hash 或 data 失败failure to load input / output capacity, lock hash, type hash or data30 / 31

只读取第一个 group 输入的 since 决定路径；since = 0 走合并路径，但并不证明当前区块早于截止（源码注释：合并输出仍是同一 lock）Only the first group input's since picks the path; since = 0 takes the merge path but does not prove the chain is before the deadline (source comment: the merged output keeps the same lock)
释放 / 退款时每个 pledge 的 amount 取 data[64..72]；若 data < 72B 或 amount > capacity，则按整个 capacity 计（超出部分不计为认捐额）On release/refund each pledge's amount is data[64..72]; if data < 72 B or amount > capacity, the whole capacity counts instead
